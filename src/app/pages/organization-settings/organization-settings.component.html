External Job Posts (Vectorized) + Candidate Fit Default on every connection

Push job posts created outside HireUp into this pool for vector search, then score any candidate resume against them with AI recommendations.

POST Create External Job Post (Vectorized)
/api/connections/{{ conn.id }}/jobposts

Create a job post entry from an external ATS/HR system. Send the external post ID plus the raw job post text (requirements etc.). The text is vectorized (embedding stored) and indexed into the vector store. Sending an existing jobpost_id again updates it.

Required Headers

X-API-Key: {{ conn.api_key || 'your_generated_api_key' }}
Content-Type: application/json
POST Request Body (JSON) 
{
  "jobpost_id": "ext-post-001",
  "jobpost_text": "Senior Python Developer. Requirements: 5+ years Python, Django, REST APIs, PostgreSQL, AWS."
}
POST Response (JSON) 
{
  "message": "Job post created and vectorized successfully",
  "jobpost_id": "ext-post-001",
  "stored_id": "uuid",
  "embedding_dim": 1536
}
